# Editable display masters

One tagged SVG master per teaching frame. `data-parent-concept-id` identifies the original meaning; `data-concept-id` identifies this separate adaptation frame. Profile groups carry `data-output-profile` and `data-export-root`. The root JSON includes the exact grid and `data-pins`. Semantic groups and unit rectangles remain editable. Skin/person tags appear where relevant; they do not automatically assign texture.

Use `../tools/regenerate.py --verify` from this directory (or `tools/regenerate.py --verify` from the collection root). See the collection README for editing and review requirements. Do not change the original or page-fit collections to edit these adaptations.
