# Symbol Library

The [completed Symbol Library release](https://github.com/sensoryapphouse/Symbol-Library/releases/tag/library-2026-11-20) contains 289,820 finished images (WebP plus native Basic SVG), arranged by style, and the verified manifests. Extract the archives into the same empty destination to reconstruct the Library folder. Check archive integrity against the release's SHA256SUMS.txt.

The [SVG collection](SVGs/) includes the high-contrast and CVI visual symbols, tactile paper and page-fit versions, and native Monarch and Dot Pad artwork with multipart teaching adaptations. It also includes editable masters and [authoring instructions](SVGs/instructions/HOW-TO-MAKE-MORE.txt).

See the [SVG artwork licence](SVGs/LICENSE.txt) for the SVG collection.

The [production scripts, saved plan and compact audit](maintenance/picom-library-20261120/README.md) record the completed 20 November 2026 update.
